Route Recorder

Records the path your car takes during the next PolyTrack editor test run and displays the recorded 3D route when you return to the editor.

  • Recording is enabled by default.
  • Toggle Record Next Run before testing.
  • Records the car's 3D position from the 0.6.2 simulation state.
  • Displays the finished route directly in the editor.

Made for PolyTrack 0.6.2.
